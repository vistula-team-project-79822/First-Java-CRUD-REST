# First Java CRUD – REST API Extension

Student ID: **79822** (Alper Tunç Ortak)

Spring Boot CRUD application with a Vaadin web interface and a REST API. The Vaadin interface and the REST API use the same `CustomerRepository`, so both operate on the same application data (H2 in-memory database, 5 sample customers loaded at startup).

## Running the application

Requirements: JDK and Git. Maven is not required, the project includes the Maven Wrapper.

```bash
git clone https://github.com/vistula-team-project-79822/First-Java-CRUD-REST.git
cd First-Java-CRUD-REST
./mvnw spring-boot:run
```

- Web interface: http://localhost:8080
- REST API base path: http://localhost:8080/api

The database is in memory, so data resets every time the application restarts.

## API endpoints

| Method | Endpoint                    | Description                                                                    | Status codes  |
| ------ | --------------------------- | ------------------------------------------------------------------------------ | ------------- |
| GET    | `/api/customers`            | Return all customers                                                           | 200           |
| GET    | `/api/customers?name=John`  | Filter customers whose first or last name contains the text (case-insensitive) | 200           |
| GET    | `/api/customers/{id}`       | Return a customer by ID                                                        | 200, 404      |
| POST   | `/api/customers`            | Create a customer                                                              | 201, 400      |
| PUT    | `/api/customers/{id}`       | Update a customer                                                              | 200, 400, 404 |
| DELETE | `/api/customers/{id}`       | Delete a customer                                                              | 204, 404      |
| GET    | `/api/customers/statistics` | Customer statistics (contributed by partner)                                   | 200           |
| GET    | `/api/info`                 | Application information                                                        | 200           |

A customer is a JSON object with `firstName` and `lastName`; `id` is generated by the application. `POST` and `PUT` return `400 Bad Request` when `firstName` or `lastName` is missing or blank. A request for an ID that does not exist returns `404 Not Found`.

## Example requests

```bash
# Get all customers
curl -i http://localhost:8080/api/customers

# Get one customer
curl -i http://localhost:8080/api/customers/1

# Filter by name
curl -i "http://localhost:8080/api/customers?name=bauer"

# Create a customer
curl -i -X POST http://localhost:8080/api/customers \
  -H "Content-Type: application/json" \
  -d '{"firstName":"John","lastName":"Smith"}'

# Update a customer
curl -i -X PUT http://localhost:8080/api/customers/1 \
  -H "Content-Type: application/json" \
  -d '{"firstName":"Jack","lastName":"Updated"}'

# Delete a customer
curl -i -X DELETE http://localhost:8080/api/customers/2

# Customer that does not exist (404)
curl -i http://localhost:8080/api/customers/999

# Statistics
curl -i http://localhost:8080/api/customers/statistics

# Application info
curl -i http://localhost:8080/api/info
```

Example responses:

```json
GET /api/info
{"studentId":"79822","applicationName":"First Java CRUD REST","version":"1.0.0"}

GET /api/customers/statistics
{"totalCustomers":5,"contributorStudentId":"79841"}
```
